# Images du jeu, dessinées en texte : « # » = noir, « . » = blanc.
#
# Chaque image commence par une ligne « @ nom » suivie de ses lignes de
# pixels (32 pixels de large au plus). Une ligne vide termine l'image.
# Dans le code C, l'image « tile_hidden » devient SPR_TILE_HIDDEN.
#
# Les cases de la grille font 8×8 pixels : la case visible occupe les
# 7×7 pixels en haut à gauche, la dernière colonne et la dernière ligne
# servent d'espacement. Le curseur inverse ces 7×7 pixels.
#
# Après modification, régénérer src/assets.c avec : make assets
